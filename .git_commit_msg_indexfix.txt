Move research/environment index into the migration step.

The `idx_decisions_environment` index references `record_environment`, a
column added by `_migrate()` for existing databases.  Creating it in the
initial `executescript` caused `no such column: record_environment` on an
old table and prevented migration from ever running.  Create the index
inside `_migrate()` after the column is guaranteed to exist.

# docs/archive — Historical Document Store

Everything here is retained for provenance and research value only. It is
**not** part of the current operating manual.

Contents:

- `audit/`, `audit-archive/`, `audits/` — dated codebase audit reports.
- `dev/` — development notes from earlier phases.
- `incident_examples/` — example/template incident write-ups.
- `plans/` — dated improvement plans (superseded).
- `prompts/` — historical agent prompt packs.
- `superpowers/` — experimental capability notes.
- Top-level `*.md`/`*.txt`/`*.json` — audit reports, research write-ups, gap
  analyses, and design proposals from the swarm/consensus era and earlier
  iterations of the 15m stack.

The current, supported documentation set lives one level up (`docs/`) and at
the repository root (`README.md`, `QUICKSTART.md`, `RUNBOOK.md`,
`ENV_SETUP.md`, `AGENTS.md`). Where these archived files conflict with the
current docs, the current docs win — MERID's production system is the lean
Kalshi 15-minute crypto stack (`web.main_15m_lean:app`, port 8011), not the
retired swarm architecture many of these documents describe.

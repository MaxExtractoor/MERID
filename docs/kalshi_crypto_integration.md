# MERID Kalshi Crypto Markets Integration

Implementation of Kalshi crypto prediction markets

**Status:** Ready for crypto market access

## Components

- **market_catalog:** Updated with enhanced crypto detection patterns
- **crypto_bot:** BTC trading scaffolding with risk management
- **api_endpoints:** Crypto status and market access endpoints
- **ui_updates:** Crypto category and educational components

## Usage

- **discovery:** `crypto_bot.discover_btc_markets()`
- **selection:** `crypto_bot.select_best_btc_market()`
- **analysis:** `crypto_bot.analyze_btc_opportunity()`
- **status:** `GET /api/crypto/status`

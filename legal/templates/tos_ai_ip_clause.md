## Trademark Registration Checklist

### United States (USPTO)

- [ ] Run clearance search (TESS + commercial search)
- [ ] Select filing basis (use in commerce or intent to use)
- [ ] Prepare mark specimen showing use
- [ ] Identify Nice classes (e.g., 9, 36, 42 for MERID)
- [ ] File TEAS application with USPTO
- [ ] Respond to Office Actions (if any)
- [ ] Submit Statement of Use (if intent-to-use)
- [ ] Monitor for opposition
- [ ] Maintain renewals (5-6 years, 9-10 years, then every 10 years)

### European Union (EUIPO)

- [ ] Search EUIPO database for conflicts
- [ ] Identify Nice classes
- [ ] File EU trademark application
- [ ] Respond to examiner queries
- [ ] Monitor opposition period (3 months)
- [ ] Maintain renewals (every 10 years)

### Recommended Nice Classes for MERID:

- **Class 9:** Downloadable software for algorithmic trading, DeFi risk management, and cryptocurrency portfolio management
- **Class 36:** Financial services, namely, cryptocurrency trading, DeFi protocol management, and digital asset custody
- **Class 42:** Software as a service (SaaS) featuring AI-powered trading algorithms and risk management tools

## License Type Recommendations

### For Proprietary MERID (Default):

**Custom EULA / SaaS Terms:**
- Treat AI-generated code, prompts, and models as confidential
- Licensed-only with no redistribution rights
- Strong IP control and protection
- Suitable for commercial, closed system

### For Source-Available Components:

**Business Source License (BSL) or Custom:**
- Allow inspection and extension
- Prohibit commercial deployment without permission
- Converts to open source after specified time period

### For Open Source Components:

**For SDKs, Clients, Utilities:**
- Apache-2.0 or MIT for permissive licensing
- Allows commercial use with attribution

**For Network Services:**
- AGPL-3.0 for copyleft over network
- Requires improvements to flow back when used over network

### For AI Models and Weights:

**Responsible AI Model License:**
- Limit harmful uses (market abuse, illegal activity)
- Preserve attribution to **[Your Entity]**
- May include usage restrictions and ethical guidelines
